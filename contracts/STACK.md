# Stack

Python3.12 standard library HTTP server and SQLite; vanilla browser HTML/CSS/JavaScript. The core UI has no pip or Node build prerequisite. The application binds IPv4 loopback for local use. `APP_CLIENT_DIR` selects the source client explicitly.

Generation is separate from the Codex development tool. Ollama is the default local generation endpoint/model; Claude is an explicit hosted alternative. Optional ASR and TTS have their own exact environment/model/account prerequisites. No engines, weights, credentials or private state are bundled.

See [setup](../docs/SETUP.md) and [capabilities](../docs/delivery/waves30/CAPABILITIES.md). Source availability, runtime availability and functional/quality acceptance are separate.
